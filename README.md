# 开水音乐 KaiShuiMusic

一个**免登录、打开即听**的多平台聚合音乐播放器。界面布局参照汽水音乐 PC 版：无边框窗口、整窗跟随封面取色、单曲推荐流（封面 + 歌词）、胶囊播放键的底部播放条。功能做减法，只保留最常用的：推荐、听歌模式、搜索、喜欢、历史播放、自建歌单、下载。

> 规划三个版本：**PC 版**（当前已完成）、**手机版**、**电视版**（手机和电视共用一套布局，已预留骨架）。

## 功能

| 模块 | 说明 |
|---|---|
| 推荐 | 单曲推荐流：左侧旋转的唱片封面、歌名歌手和喜欢，右侧滚动歌词；滚轮或 ↑↓ 切歌，播完自动续播 |
| 听歌模式 | 频道电台：常用模式（熟悉、新鲜、Chill、专注……）和按曲风 / 场景的更多模式，点一下连续播放 |
| 任务栏播放器 | PC 版嵌在 Windows 任务栏里的小播放器：封面、歌名、当前歌词、切歌和喜欢，背景透明融入任务栏 |
| 主题色 | 整个窗口（侧边栏、内容区、播放条）跟随当前歌曲封面取色 |
| 搜索 | 单曲 / 歌单 / 专辑，6 个平台聚合搜索，按来源筛选；支持粘贴分享链接直接解析；搜索历史 + 热搜榜 |
| 播放 | 底部播放条（顶边进度线、胶囊播放键、音源 / 词 / 循环 / 音量 / 列表）、播放列表、三种播放模式、媒体键、空格暂停 |
| 自动换源 | 汽水会员歌曲或失效歌曲会自动匹配其它平台的同一首歌，**无需登录也能听完整版** |
| 我的音乐 | 我喜欢的音乐、历史播放、本地下载、创建的歌单（收藏到歌单）、收藏的歌单；数据存在本机，无需账号 |
| 下载 | 一键下载到本地，自动选完整音源，尽量写入封面和歌词（需要 ffmpeg） |

## 架构

```
┌──────────── 前端 web/（Vue 3 + Vite + TS，三端共用）───────────┐
│  layouts/PcLayout      侧边栏 + 顶栏搜索 + 底部播放条（PC）     │
│  layouts/MobileLayout  顶部搜索 + 底部导航 + 迷你播放条（手机/电视）│
│  views/ components/    页面与组件（各端共用）                  │
│  stores/player         播放核心：队列 / 模式 / 歌词 / 换源      │
│  platform.ts           识别 pc / mobile / tv，切换布局          │
└──────────────────────────────┬─────────────────────────────────┘
                               │ JSON API（/api/*）
┌──────────── 后端 server/（Go）──────────────────────────────────┐
│  internal/api      HTTP 接口、音频流代理（支持 Range 拖动）      │
│  internal/music    首页聚合、推荐流、搜索、详情、可播放性解析与换源 │
│  internal/library  喜欢 / 历史 / 自建歌单 / 收藏歌单（本地 JSON）│
│  cmd/kaishui-desktop  PC 桌面版：内置服务 + WebView2 窗口        │
│  cmd/kaishui          服务版：浏览器、手机、电视通过局域网访问     │
└──────────────────────────────┬─────────────────────────────────┘
                               │ Go 包直接调用
          go-music-dl/core + music-lib（各平台接口、汽水解密、下载）
```

### 复用了什么，没复用什么

- **复用** [go-music-dl](https://github.com/guohuiyuan/go-music-dl) 的 `core` 包及其依赖 `music-lib`：各平台的搜索、歌单、榜单、歌词、播放地址、汽水音频解密、下载与元数据写入。这部分涉及各平台接口逆向，平台变动频繁，跟随上游维护最省事。
- **没有复用** 它的网页界面（服务端模板 + APlayer）、Rust/Gio 桌面壳和安卓壳。界面、接口层、桌面壳都是新写的，接口专门为三端设计。
- 换源匹配算法参考了 go-music-dl 的实现（它在 `internal` 包里无法直接引用），在 `server/internal/music/resolve.go` 中做了精简移植。

## 开发

需要 Node.js 18+ 和 Go 1.25+。

```bash
# 终端 1：启动后端（默认 http://127.0.0.1:8686）
cd server
go run ./cmd/kaishui
```

```bash
# 终端 2：启动前端开发服务（http://localhost:5173，/api 自动代理到后端）
cd web
npm install
npm run dev
```

浏览器访问 `http://localhost:5173/?platform=mobile` 或 `?platform=tv` 可以预览手机 / 电视布局。

## 构建 PC 版

```powershell
.\build.ps1
```

产物在 `dist/`：

- `KaiShuiMusic.exe`：桌面版，双击运行（依赖系统自带的 WebView2，Windows 10/11 一般已内置）
- `kaishui.exe`：服务版，`kaishui.exe --addr 0.0.0.0:8686` 后同一局域网的手机、电视用浏览器访问 `http://电脑IP:8686` 即可使用

数据目录：`%AppData%\KaiShuiMusic`（喜欢、历史、设置），默认下载目录为其中的 `data\downloads`，可在设置里修改。

## 手机 / 电视版规划

已预留的部分：

- `platform.ts` 自动识别平台（也可用 `?platform=` 强制指定），`App.vue` 按平台切换布局
- `MobileLayout.vue`：底部导航 + 迷你播放条 + 全屏播放页，已能基本使用
- `utils/spatialNav.ts`：电视遥控器方向键焦点导航；`.platform-tv` 放大字号和焦点框
- `api/index.ts` 支持配置服务地址，手机 / 电视可连接局域网内的电脑
- 后端接口与平台无关，`/api` 已开启跨域

后续计划：安卓 App 用同一套 Web 界面（WebView），Go 核心通过 gomobile 编译进 App 本地运行（不依赖电脑）；电视版即安卓 TV，补充 Leanback 启动入口和遥控器交互细节。
